# Kids Sandbox 🧪

A safe place to play with code. You can't break anything here, so go wild!

## Web (no installs)
Open `web/index.html` in your browser. Edit the file, save, refresh. Done!
Try the challenges in `web/CHALLENGES.md`.

## Python
Install Python from python.org, then run:

    python python/hello.py
    python python/turtle_art.py
    python python/guess.py

Try the challenges in `python/CHALLENGES.md`.

## Rules of the sandbox
1. Change anything. Break things. That's how you learn.
2. Stuck? Undo with `git checkout .` (grown-up helps!) or ask for help.
3. Never put passwords or personal info in these files.
